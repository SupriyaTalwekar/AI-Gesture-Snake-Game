# AI-Gesture-Snake-Game
A classic Snake Game controlled with hand gestures using OpenCV.

## Features
- Control the snake using hand gestures (no keyboard needed).
- Built with Python, OpenCV, and MediaPipe.
- Real-time hand tracking for smooth gameplay.
- Fun, interactive, and AI-powered gaming experience.

## Tech Stack
- Python 3
- OpenCV
- MediaPipe
- NumPy
